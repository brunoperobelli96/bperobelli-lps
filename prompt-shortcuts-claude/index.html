    Como usar os atalhos

    Não é um prompt novo. É um complemento do que você já escreve.

    01

    Escreva seu pedido normal

    Pergunte o que precisar, do jeito que você já faz hoje.

    "Explica o que é inflação"
    02

    Cole o atalho no final

    Adicione o código de um dos atalhos da lista, sem mais nada.

    "Explica o que é inflação /eli5"
    03

    Receba a resposta no formato certo

    O Claude entende o atalho como instrução de formato e tom.

    Resposta simples, como se você tivesse 5 anos

    Dica: atalhos com barra (/deepthink) e sem barra (BEASTMODE) funcionam do mesmo jeito. Use o que vier no fluxo da frase.
