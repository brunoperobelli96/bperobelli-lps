Pare de mandar PDF pro Claude e gaste bem menos do seu limite

O MarkItDown, uma ferramenta gratuita da Microsoft, transforma PDF, Word, Excel e PowerPoint em texto limpo antes do Claude ler. Você instala uma vez no Claude Desktop e depois é só pedir.

Gratuito Da Microsoft Claude Desktop

O que você vai encontrar aqui

  • Por que o PDF come tanto do seu limite
  • Instalação em 4 passos, pra quem nunca mexeu nisso
  • O pedido certo pra fazer ao Claude
  • Como fazer o mesmo no ChatGPT
O problema

Cada página do PDF vira uma imagem

Quando você arrasta um PDF pro Claude, ele lê o texto e também uma foto de cada página. É por isso que um arquivo grande consome tanto do seu limite antes da primeira pergunta.

Passo a passo · Claude Desktop

Instale uma vez e use pra sempre

Funciona no Claude Desktop, o aplicativo do Claude no computador (Windows ou Mac). No site e no celular não dá pra instalar.

◐ Confirmado em partes, teremos que testar!
1

Instale o Python

O MarkItDown roda com o Python, um programa gratuito. Baixe em python.org/downloads e instale.

No Windows, marque a caixinha "Add python.exe to PATH" na primeira tela da instalação.

2

Instale o MarkItDown

Abra o Prompt de Comando (Windows) ou o Terminal (Mac), cole a linha abaixo e aperte Enter.

pip install markitdown-mcp
3

Ligue o MarkItDown no Claude

No Claude Desktop, vá em Configurações → Desenvolvedor → Editar configuração. Abre um arquivo de texto. Cole isto dentro dele e salve:

{ "mcpServers": { "markitdown": { "command": "markitdown-mcp" } } }

Se o arquivo já tiver outros conectores, coloque só o bloco "markitdown" dentro do "mcpServers" que já existe.

4

Feche o Claude por completo e abra de novo

Não basta fechar a janela: saia do aplicativo (no Windows, pelo ícone perto do relógio; no Mac, Cmd + Q). Quando abrir de novo, o MarkItDown aparece na lista de ferramentas do chat.

★

Peça pro Claude converter

Em vez de arrastar o PDF, diga onde ele está no seu computador:

Converte o arquivo [cole aqui o caminho do arquivo] com o MarkItDown e depois me faz um resumo dos pontos principais em tópicos.
Pegar o caminho no WindowsSegure Shift, clique com o botão direito no arquivo e escolha "Copiar como caminho".
Pegar o caminho no MacClique com o botão direito no arquivo, segure Option e escolha "Copiar como nome do caminho".

Funciona com: PDF, Word, Excel e PowerPoint. Arquivo que é só foto escaneada pode sair sem texto, porque não tem letra pra extrair.

Usa ChatGPT?

No ChatGPT, converta antes e cole o texto

O ChatGPT não aceita esse conector instalado no seu computador. Mas dá pra usar o MarkItDown por fora: depois do passo 1, rode as linhas abaixo no Prompt de Comando ou no Terminal, abra o arquivo .md que ele cria e cole o texto no ChatGPT.

pip install "markitdown[all]" markitdown seu-arquivo.pdf -o seu-arquivo.md
