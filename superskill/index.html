Como funciona

Você pede, ela procura e instala

Skill é um manual que ensina o Claude a fazer uma tarefa do jeito certo. O problema é achar a skill boa no meio de mais de um milhão. A find-skills faz essa busca por você.

1

Você diz o que quer

Em português mesmo, do seu jeito. Por exemplo: "quero fazer vídeos pras minhas redes".

2

Ela procura no diretório

Olha o ranking do skills.sh e escolhe pelas instalações, por quem publicou e pelas estrelas no GitHub. Depois te mostra as que servem.

3

Ela instala

Você escolhe e a skill vai direto para o seu Claude Code, com um comando só. A partir daí, o Claude já sabe fazer aquilo.

Instalação · 1 minuto

Instale com um comando só

A find-skills é publicada pela Vercel (vercel-labs) e é aberta no GitHub.

  1. Passo 1

    Tenha o Node.js

    O comando de instalação usa o npx, que vem junto com o Node.js. Se você já usa o Claude Code, provavelmente já tem. Se não tiver, baixe a versão LTS em nodejs.org. É gratuito.

  2. Passo 2

    Cole o comando no terminal

    Abra o terminal, cole a linha abaixo e aperte Enter. É o comando que aparece na página oficial da skill.

    npx skills add https://github.com/vercel-labs/skills --skill find-skills
    Página da find-skills no skills.sh ↗ Código no GitHub ↗
  3. Passo 3

    Abra o Claude Code e peça

    Pronto. Agora é só pedir uma skill para o que você quer fazer. Os pedidos prontos estão logo abaixo.

Como saber se uma skill vale a pena

Diretório aberto quer dizer que qualquer pessoa publica. Os mesmos critérios que a find-skills usa servem para você conferir.

1

Instalações

Prefira skills com mais de mil instalações. Muita gente usando é sinal de que funciona.

2

Quem publicou

Fontes conhecidas, como Vercel e Anthropic, são a aposta mais segura.

3

Auditoria

A página de cada skill no skills.sh mostra verificações de segurança. Dê uma olhada antes de instalar.

Dica: peça para o Claude mostrar as opções antes de instalar. Assim você vê o número de instalações e quem publicou cada uma, e decide.
