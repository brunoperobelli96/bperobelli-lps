PASSO A PASSO

As 3 configurações para mudar agora

Siga na ordem. Cada uma leva menos de 10 segundos.

1

Desligar o uso das conversas para treinar o modelo

Configurações → Controle de dados → Melhorar o modelo para todos

Desliga essa opção. Com ela ativa, suas conversas são usadas pra alimentar o treinamento do ChatGPT. Desligando, elas param de virar dado de treinamento.

2

Gerenciar o que está salvo na sua memória

Configurações → Personalização → Resumo de memória → Gerenciar

É ali que fica tudo que o ChatGPT aprendeu sobre você: nome da empresa, projetos, hábitos, rotina. Revise a lista e apague qualquer coisa que não quer que continue salva.

3

Ativar o chat temporário (modo incógnito)

Canto superior direito → Chat temporário

Funciona como modo incógnito: nada que você digitar fica salvo no histórico nem nas memórias. Ideal para conversas que você não quer que influenciem o perfil do sistema sobre você.

CONFIGURAÇÕES EXTRAS

Mais 4 ajustes que valem a pena

Não estão no vídeo, mas completam a proteção.

Exportar seus dados

Configurações → Controle de dados → Exportar dados

Baixa tudo que o ChatGPT tem sobre você. Bom pra saber exatamente o que está armazenado antes de decidir o que apagar.

Apagar todo o histórico

Configurações → Controle de dados → Excluir todas as conversas

Apaga tudo de uma vez. Útil se você usou o ChatGPT por muito tempo sem se preocupar com o que estava salvando.

Desativar a memória completamente

Configurações → Personalização → Memória → desligar

Desliga tudo de uma vez, sem precisar apagar item por item. O ChatGPT para de aprender qualquer coisa nova sobre você.

Verificar aplicativos conectados

Configurações → Segurança → Aplicativos conectados

Mostra todos os apps com acesso à sua conta. Revogue qualquer um que você não usa mais ou que não reconhece.

PROMPTS DE AUDITORIA

Pergunte pro ChatGPT o que ele sabe sobre você

Cole esses prompts diretamente no chat para auditar suas informações antes de decidir o que apagar.

Prompt 1

Auditoria completa da memória

"Faça uma auditoria completa das informações que você tem salvas sobre mim. Liste por categorias: dados pessoais, empresa, projetos, hábitos e qualquer outra coisa que identificar. Seja específico e não omita nada."

Prompt 2

Checklist do que remover

"Com base no que você sabe sobre mim, quais informações são sensíveis ou que eu deveria remover da sua memória? Me dá uma lista para eu revisar agora, com a justificativa de por que cada item é sensível."

Prompt 3

Guia de proteção de privacidade

"Me dá um guia prático: quais tipos de dados eu nunca deveria digitar numa conversa com IA? Quero proteger informações pessoais, financeiras e profissionais. Lista as categorias com exemplos reais de cada uma."
