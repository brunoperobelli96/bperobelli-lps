O que é o Claude Code?

Claude Code é uma ferramenta de programação com IA que funciona direto no seu computador — no terminal. Diferente do Claude normal, ele não sugere código: ele executa, testa e corrige sozinho. Pense como um programador sênior trabalhando no seu projeto enquanto você dorme. Os plugins são extensões que deixam ele ainda mais poderoso — como apps que você instala no celular para adicionar funções novas.

Plugin 01

Superpowers

Faz o Claude pensar antes de agir

Sem esse plugin, o Claude entra direto no código sem planejar — como um pedreiro que começa a construir sem ver a planta. Com o Superpowers, ele para, planeja, divide o trabalho em partes menores e só então executa. A diferença na qualidade é absurda.

Ideal para quem
  • Quer código mais organizado e sem gambiarras
  • Cansa de o Claude "sair fazendo" sem entender o contexto
  • Trabalha em projetos maiores ou mais complexos
⭐ 105K+ estrelas no GitHub 👤 Jesse Vincent
obra/superpowers
Passo a passo

Abra o terminal (Mac: Command + Espaço → "Terminal". Windows: Win + R → "cmd"). Com o Claude Code aberto, cole o comando abaixo e pressione Enter:

claude /install obra/superpowers

Plugin 02

Frontend Design

Elimina o visual genérico de IA

Todo app criado por IA parece igual — visual roxo insosso, fonte sem personalidade, layout de template. Feito pela própria Anthropic, esse plugin força o Claude a usar fontes bonitas, paletas com personalidade e layouts que parecem produto de verdade.

Ideal para quem
  • Quer que o resultado final pareça profissional
  • Está construindo um produto ou protótipo para clientes
  • Não tem designer no time e precisa de visual decente
📦 277K+ instalações 🏢 Anthropic
anthropics/frontend-design
Passo a passo

Plugin oficial da Anthropic. Ativa automaticamente quando você mexe em arquivos de interface (.tsx e .jsx). Para instalar:

claude /install anthropics/frontend-design

Plugin 03

Code Review

4 agentes revisando ao mesmo tempo

Não precisa instalar nada. São 4 agentes rodando em paralelo, cada um olhando seu código de um ângulo diferente: um verifica regras do projeto, outro caça bugs, outro lê o histórico do Git. Zero ponto cego, sem falso alarme.

Ideal para quem
  • Quer garantir que o código não vai quebrar antes de publicar
  • Trabalha em projeto com histórico longo de mudanças
  • Quer uma segunda opinião antes de enviar para produção
✅ Nativo no Claude Code 👤 Boris Cherny (Anthropic)
anthropics/claude-code
Não precisa instalar

Já vem embutido no Claude Code. Para usar, é só digitar o comando abaixo — ele sobe 4 agentes automaticamente e só mostra problemas com confiança acima de 80%.

claude /code-review

Plugin 04

Security Guidance

Acha a falha antes do invasor

Monitora cada arquivo que você escreve ou edita em tempo real. Se encontrar uma vulnerabilidade crítica — uma brecha que um hacker poderia explorar — ele bloqueia a alteração antes de você salvar. Você não precisa ser especialista em segurança. Ele é.

Ideal para quem
  • Está construindo algo que vai receber dados de usuários
  • Não tem experiência em segurança
  • Quer publicar sem medo de brechas óbvias
📦 87K+ instalações 🏢 Anthropic
anthropics/security-guidance
Passo a passo

Após instalado, age automaticamente em segundo plano — você não precisa fazer nada diferente. Só instala e ele já fica de olho em cada arquivo modificado.

claude /install anthropics/security-guidance

Plugin 05

Claude-Mem

Nunca mais explique tudo de novo

Toda vez que você abre uma sessão nova no Claude Code, ele esquece tudo — seu projeto, suas regras, suas preferências. Com o Claude-Mem, a sessão 49 já sabe tudo que a sessão 48 aprendeu. Tudo salvo localmente, sem nada ir para a nuvem.

Ideal para quem
  • Trabalha no mesmo projeto por dias ou semanas
  • Tem regras e convenções específicas no projeto
  • Cansa de repetir contexto toda vez que abre o terminal
⭐ 38K+ estrelas no GitHub 👤 Alex Newman
thedotmack/claude-mem
Passo a passo

Após instalado, grava automaticamente o que o Claude aprende em cada sessão — decisões, convenções, preferências. Na próxima sessão, injeta esse contexto automaticamente. 100% local.

claude /install thedotmack/claude-mem

Plugin 06

Gstack

Um time inteiro num único plugin

Criado pelo Gary Tan, CEO da Y Combinator — a aceleradora por trás do Airbnb, Stripe e Dropbox. São 6 habilidades e 24 comandos: agente de CEO, engenheiro, designer, QA e responsável pelo lançamento. O agente de CEO pergunta "devemos construir isso?" antes do engenheiro perguntar "como construir". Essa ordem muda tudo.

Ideal para quem
  • Quer um fluxo completo do planejamento até o lançamento
  • Está construindo sozinho e precisa de múltiplas perspectivas
  • Já se sente confiante com Claude Code e quer ir além
⭐ 20K+ estrelas no GitHub 👤 Garry Tan (CEO, YC)
garrytan/gstack
Passo a passo

Após instalar, você terá 24 comandos novos. Fluxo recomendado: /plan-ceo-review para validar a ideia → /plan-eng-review para arquitetura → /qa para testar → /ship para lançar.

claude /install garrytan/gstack
Como usar junto

O fluxo com os 6 ativos

Quando você instala todos, eles trabalham em conjunto automaticamente — cada um entrando na hora certa.

→ Sessão começa: Claude-Mem injeta o contexto da última sessão automaticamente — sem explicar nada de novo.
→ Você pede algo: Superpowers entra em ação e força o Claude a planejar antes de começar a codar.
→ Claude escreve arquivos de interface: Frontend Design ativa automaticamente e garante visual profissional.
→ Qualquer arquivo é salvo: Security Guidance escaneia em tempo real e bloqueia vulnerabilidades antes de gravar.
→ Antes de publicar: você roda /code-review — 4 agentes vasculham o projeto de ângulos diferentes.
→ Se estiver usando Gstack: /ship cuida do PR, do CI e do deploy — quatro agentes, zero etapa manual.
