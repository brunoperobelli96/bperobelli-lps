PASSO A PASSO

Os 3 códigos para estudar qualquer assunto

Abra o ChatGPT, envie cada código substituindo [seu capítulo] pelo assunto que você precisa aprender. Use os três na mesma conversa.

Código 1

/doublekiller — Elimine as dúvidas

/doublekiller [seu capítulo]

Identifica as dúvidas mais comuns que os alunos têm sobre aquele assunto e esclarece cada uma. Ideal para começar antes de qualquer coisa.

Código 2

/exam — Preveja o que vai cair

/exam [seu capítulo]

Cria as perguntas com maior chance de cair na prova, junto com as respostas modelo para você revisar. Você vai estudar exatamente o que importa.

Código Bônus

/flashcards — Revisão ativa

/flashcards [seu capítulo]

Transforma o assunto inteiro em cartões de pergunta e resposta para testar de verdade em vez de só reler. É o método mais eficaz para fixar o conteúdo.
