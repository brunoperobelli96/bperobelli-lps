Milhares de pessoas testando a sua ideia, sem nenhuma existir

O MiroFish cria milhares de pessoas simuladas, cada uma com personalidade, memória e opinião própria, e solta todas numa rede social de mentira pra reagir à sua ideia. No fim, um agente escreve um relatório e você ainda conversa com quem quiser.

Como funciona

Da sua ideia ao relatório

Você descreve a ideia em português, do seu jeito, ou sobe um material (um relatório, uma notícia). O MiroFish faz o resto nestas 5 etapas.

1

Monta a memória

Lê o seu material, tira as informações importantes e monta um mapa do assunto.

2

Cria as pessoas

Gera os personagens, cada um com personalidade, memória e jeito de agir próprios.

3

Simula

Solta todo mundo em duas redes sociais simuladas ao mesmo tempo. Eles postam, comentam, discutem e mudam de opinião.

4

Escreve o relatório

Um agente analisa tudo e conta quem gostou, quem rejeitou e por quê.

5

Você conversa

Pergunte direto para qualquer pessoa da simulação ou para o agente do relatório.

Passo a passo · sem terminal

Instale em 3 passos

Você não precisa saber programar. Quem digita os comandos é o Claude Code: você só pega duas chaves e cola um pedido pronto.

  1. Passo 1

    Pegue as duas chaves

    Chave é uma espécie de senha que deixa o MiroFish usar um serviço em seu nome. Você vai precisar de duas. Guarde as duas num bloco de notas por enquanto.

    Chave da IA (escolha uma)

    Claude: crie a conta no Claude Console, coloque créditos e crie uma chave em API Keys. O uso é cobrado por consumo.

    Qwen: é a IA que o próprio projeto recomenda. A chave sai do Alibaba Bailian.

    Chave do Zep (grátis)

    O Zep guarda a memória das pessoas simuladas. Crie a conta em app.getzep.com e gere a chave. Segundo o projeto, o plano grátis do mês dá para o uso simples.

  2. Passo 2

    Peça para o Claude Code instalar

    Abra o Claude Code (no app do Claude para computador, na aba Code), copie o pedido abaixo e mande. Ele confere o que falta no seu computador, instala e baixa o MiroFish. Se ele pedir permissão para rodar algum comando, é só aprovar.

    Instale o MiroFish no meu computador: https://github.com/666ghj/MiroFish 1. Confira se eu tenho Node.js 18 ou mais novo, Python 3.11 ou 3.12 e o uv. Se faltar algum, me explique em uma frase e instale. 2. Baixe o projeto com git clone e entre na pasta. 3. Crie o arquivo .env a partir do .env.example e me diga onde ele está. Não me peça as chaves aqui no chat: eu mesmo colo no arquivo. 4. Quando eu avisar que colei as chaves, rode npm run setup:all e depois npm run dev. 5. Quando estiver rodando, me diga para abrir http://localhost:3000.
  3. Passo 3

    Cole as chaves e abra

    Abra o arquivo .env que o Claude Code indicou (pode ser no Bloco de Notas ou no TextEdit), apague o que estiver lá e cole as linhas da IA que você escolheu, trocando sua_chave pelas suas chaves. Salve, avise o Claude Code e, quando ele terminar, abra http://localhost:3000 no navegador. É ali que você escreve a ideia.

    Se você escolheu o Claude

    LLM_API_KEY=sua_chave_do_claude LLM_BASE_URL=https://api.anthropic.com/v1/ LLM_MODEL_NAME=claude-haiku-5-5 ZEP_API_KEY=sua_chave_do_zep

    Se você escolheu o Qwen

    LLM_API_KEY=sua_chave_do_qwen LLM_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1 LLM_MODEL_NAME=qwen-plus ZEP_API_KEY=sua_chave_do_zep

    Sobre o Claude: o Haiku 5.5 é o modelo mais barato (dá para trocar por claude-sonnet-5-5 ou claude-opus-5-5, que custam mais). Não é o caminho padrão do projeto: a Anthropic diz que essa entrada serve principalmente para testar e comparar modelos. O MiroFish se adapta quando a IA recusa o formato que ele pede, então deve funcionar. Documentação da Anthropic

Pré-requisitos: Node.js 18+, Python 3.11 ou 3.12 e uv. Rode na ordem, preenchendo o .env (passo 3 acima) antes do setup.

git clone https://github.com/666ghj/MiroFish.git
cd MiroFish
cp .env.example .env
npm run setup:all
npm run dev

Com Docker: depois do cp .env.example .env, rode docker compose up -d. Site em localhost:3000, simulação em localhost:5001.

Pedido pronto

O que escrever pra testar

Diga quem é o público, o que você quer lançar e o que quer descobrir. Quanto mais específico, mais útil o relatório.

Do vídeo

Quero lançar um app de finanças pessoais para jovens de 18 a 25 anos que guarda dinheiro sozinho a cada compra. Simule como esse público reage ao lançamento e me diga o que faria eles assinarem.

Para o seu negócio

Vou lançar [o que você vai lançar] para [quem é o público], por [preço]. Simule como esse público reage, quais objeções aparecem e o que mudaria a opinião de quem rejeitou.
Antes de confiar no resultado

Termômetro, não bola de cristal

O MiroFish mostra onde a ideia quebra antes de você investir. Use sabendo destes três limites.

1

Não são clientes de verdade

São papéis interpretados pela mesma IA. Ninguém provou ainda que as previsões acertam.

2

A IA muda a resposta

Trocar a IA por trás pode mudar o resultado. Rode mais de uma vez antes de tirar conclusão.

3

Gasta bastante

O próprio projeto avisa que o consumo de IA é alto. Comece com menos de 40 rodadas de simulação.
