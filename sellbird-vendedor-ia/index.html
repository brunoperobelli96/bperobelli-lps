Um vendedor de IA que acha clientes para você, no seu computador

O Sellbird, antes chamado Harvey, é um projeto aberto que usa o seu plano do Claude para achar empresas, descobrir quem decide, escrever e-mails curtos e levar a conversa até a reunião. Nada sai sem você aprovar.

Como funciona

O ciclo completo, em 7 etapas

Cada etapa roda no seu computador e fica à vista no painel.

Confirmado em partes, teremos que testar!
  1. 1

    Aprende o seu negócio

    Você passa o site da sua empresa e ele entende o que você vende e quem é o seu cliente ideal. No terminal, o comando é sellbird train.

  2. 2

    Procura empresas

    Busca negócios parecidos com o seu cliente ideal. A fonte padrão é o OpenStreetMap, que é gratuita. Fontes pagas mostram o custo antes de rodar.

  3. 3

    Lê os sinais de compra

    Lê o site de cada empresa atrás de sinais que você confirma, como falta de agendamento online, anúncios rodando ou uma vaga aberta. Essa etapa não usa o modelo de IA.

  4. 4

    Acha quem decide

    Procura o dono ou o gerente citado nas páginas da empresa, até duas pessoas por empresa.

  5. 5

    Verifica o e-mail

    Aprende o padrão de e-mail da empresa e confere o endereço. Cada um recebe um rótulo: verificado, arriscado, palpite ou inválido. Só vai para os que podem receber.

  6. 6

    Escreve e envia

    Monta uma sequência curta por pessoa, por exemplo dois e-mails, citando o que encontrou. Envia pelo Gmail, Microsoft 365 ou SMTP, respeitando um limite diário e o horário comercial de quem recebe.

  7. 7

    Responde e acompanha

    Lê as respostas, rascunha a continuação, separa respostas automáticas, respeita o pedido de descadastro na hora e sinaliza o que não deve responder sozinho.

Funcionalidades

O que mais vem junto

Além do ciclo principal, o projeto traz ferramentas para você acompanhar, travar e exportar.

📊

Painel no seu navegador

Um painel local, em 127.0.0.1:5555, com as telas Hoje, Caixa de saída, sinais e busca de contatos. Tem modo escuro.

📤

Exporta a lista

O comando sellbird export gera um CSV com os prospectos, pronto para quem só quer a lista.

🧾

Playbooks editáveis

As regras de venda e os prompts são arquivos na sua pasta. Você muda o tom e o jeito de abordar.

🚧

Checagem antes do envio

Barra e-mail com campo em branco, frase proibida, texto longo demais, link extra e endereço inválido, sem usar IA.

⏸️

Botão de pausa

O comando sellbird sending pause para todos os envios de uma vez.

🔁

Ciclo automático

O comando sellbird run roda em ciclos e dorme entre eles. No exemplo do projeto, o intervalo é de 15 minutos.

🧩

Extensões

Dá para adicionar rotas, comandos e etapas por um pacote separado.

☁️

Versão hospedada

Por que vale

O que você ganha com isso

💸

Custo baixo

O software é gratuito. Você paga o seu plano do Claude e uma caixa de e-mail, que no Google Workspace custa cerca de US$ 7 por mês.

Sem chave de API

Usa o login do seu Claude Pro ou Max. Não tem cobrança por token.

✋

⏱️

Prospecção sem planilha

Da busca à resposta, o trabalho repetitivo fica com o agente e você cuida da conversa.

Antes de começar

O que você precisa ter

  • ✓Python 3.11 ou mais novo. O macOS vem com o 3.9, então instale um novo (por exemplo, brew install python@3.13).
  • ✓Claude Pro ou Max com o Claude CLI conectado (claude login). Também funciona com um plano do ChatGPT usando o Codex CLI.
  • ✓Uma caixa de e-mail para enviar. O recomendado é o Google Workspace em um domínio separado só para prospecção. Também aceita Microsoft 365 ou SMTP.
  • ✓Aquecimento da caixa. O projeto recomenda aquecer o e-mail antes de enviar em volume. O link que ele indica é de afiliado.

Terminal: o Sellbird roda por linha de comando. Os comandos do projeto são para macOS e Linux. No Windows, vale pedir ao próprio Claude Code para adaptar.

Instalação

Duas formas de instalar

A mais fácil é deixar o Claude Code montar tudo para você.

Opção A · Guiada

Deixe o Claude Code instalar

Rode estes três comandos no terminal. Quando o Claude abrir, diga a frase do bloco seguinte.

Terminal 
git clone https://github.com/ethanplusai/sellbird.git
cd sellbird
claude
Opção A · Frase

Peça a instalação

Cole no Claude Code, dentro da pasta do projeto.

Frase 
set up Sellbird for me
Opção B · Manual

Instale na mão

Troque o endereço do site pelo da sua empresa. Os demais comandos são os do projeto.

Terminal 
python3.13 -m venv .venv && source .venv/bin/activate && pip install -e .
cp .env.example .env
sellbird train https://seu-site.com.br
sellbird signals --confirm free
sellbird discover
sellbird dashboard
sellbird run

Antes de usar

Cuidados que você precisa ter

E-mail frio tem regras

Prospectar por e-mail envolve dados pessoais e pode ter regras próprias, como a LGPD no Brasil. O projeto não detalha isso. Pesquise e, se precisar, consulte um advogado.

Proteja o seu domínio

Use um domínio separado para prospecção e aqueça a caixa antes de enviar. Se o domínio cair em spam, o e-mail principal da empresa não deve ser afetado.

O nome mudou

O Harvey virou Sellbird na versão 0.4.0. O comando antigo (harvey) ainda funciona, mas será removido. Quem já usava o Harvey deve ler a seção de atualização do projeto.

A licença mudou

O Sellbird usa a licença AGPL-3.0. As versões do Harvey até a 0.3 eram MIT. Se você pretende modificar e oferecer como serviço, leia a licença.
