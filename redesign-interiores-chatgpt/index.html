PASSO A PASSO

Os 2 prompts para redesenhar qualquer cômodo

Envie uma foto do seu ambiente, cole o primeiro prompt e siga para o segundo na mesma conversa.

Prompt 1

Redesign de alto padrão

Aqui está uma foto do meu cômodo. Reprojete-o como um arquiteto de interiores de alto padrão faria. Preserve a estrutura original, mas otimize layout, iluminação, materiais, mobiliário e decoração para criar um ambiente sofisticado, acolhedor e funcional. O resultado deve parecer uma fotografia real de um projeto executável.

O ChatGPT gera imagens e entrega um projeto de redesign completo do seu cômodo.

Prompt Bônus

Lista de compras executável

Agora transforme esse projeto em uma versão executável. Priorize os itens com maior impacto visual por real investido, liste cada item com preço estimado, link da Amazon ou do Mercado Livre e justifique brevemente sua escolha.

O ChatGPT devolve a lista de compras completa com preço e link real para você montar o ambiente de verdade.

POR QUE FUNCIONA

De sonho a projeto executável em dois prompts

O ChatGPT combina visão de design com dados reais de mercado para transformar uma foto qualquer num projeto concreto, com lista de compras pronta para usar.

🏠

Projeto visual realista

O ChatGPT gera imagens que parecem fotografias reais de projetos executáveis, preservando a estrutura do seu cômodo.

🛒

Lista de compras com links

Cada item vem com preço estimado e link direto da Amazon ou Mercado Livre — sem precisar pesquisar nada por conta própria.

💡

Custo-benefício por item

O ChatGPT prioriza o que gera mais impacto visual por real investido e justifica cada escolha antes de você comprar.
